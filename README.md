# Ember Creeper Boy Minecraft Skin

A high-quality 64x64 Minecraft skin texture featuring a nether-themed teenage boy with messy brown hair, glowing red eyes, a fiery orange and dark red creeper hoodie with burning ember effects, black face mask, dark tactical pants, and combat boots. This game asset is designed in authentic Minecraft skin style with crisp edges and a complete SVG source file.

## Install

1. Download the `skin_nether_boy.svg` file from the project repository.
2. Open the SVG file in any image editor that supports SVG (e.g., Inkscape, GIMP, or an online converter) and export it as a 64x64 PNG image.
3. Alternatively, use an online SVG-to-PNG converter with the output size set to 64x64 pixels.

## Use

1. Launch Minecraft Java Edition.
2. Navigate to **Skin** in the main menu, then select **Skin Customization**.
3. Click on the **Browse** button next to the skin selection.
4. Select the exported 64x64 PNG file.
5. Apply the skin and enter the game to see "Ember Creeper Boy" on your character.
